# im-locked-in-site

Public pages for the I'mLockedIn iOS and watchOS app, served by GitHub Pages at https://myboringapps.github.io/im-locked-in-site/

- `privacy.html`: Privacy Policy (App Store "Privacy Policy URL")
- `support.html`: Support (App Store "Support URL")
- `terms.html`: Terms of Use (linked from the paywall and Settings)

Plain HTML and CSS, no build step. Edit a page, commit, push; GitHub Pages updates within a minute.
The app lives in a separate repository (`myboringapps/im-locked-in`, local folder `../Im Locked In App`).
